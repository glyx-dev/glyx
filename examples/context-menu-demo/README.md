# context-menu-demo

Right-click a card to open its context menu (`@glyx-dev/context-menu`). The menu opens at the pointer, above everything else; The first two cards use the drawn menu (icons, shortcut labels, a check mark, submenus), the last two the operating system's own (`native`). Every choice reports itself in the line below the cards. Arrow keys move through the items, Enter chooses, Escape or a click anywhere else closes it.

```bash
cd examples/context-menu-demo
glyx dev
```
