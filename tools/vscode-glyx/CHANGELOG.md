### Added
- `Glyx: Open DevTools on…` (`glyx.openDevtoolsPanel`) asks which DevTools panel to open and opens it directly. The panel id travels in the DevTools URL, so the UI starts on it.
- `Glyx: Copy MCP Server Config` (`glyx.copyMcpConfig`) copies a ready-to-paste `mcpServers` entry that runs `glyx mcp`, for an AI agent's MCP settings.
